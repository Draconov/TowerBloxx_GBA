# Tower Bloxx v1.5.22 menu compositor recovery

This note records the evidence used by the screenshot-driven menu fidelity pass.
It deliberately separates **rendering facts** from still-unrecovered menu-state
semantics.

## Reference branch

The played v1.5.22 JAR capture is not the device-specific plain-white menu
fallback previously modeled by the GBA port.  `k.b(Graphics)` has two visual
branches.  The capture matches the default branch, where the menu palette is
read from resource `m`.

The nine 24-bit palette entries at the head of `m` are:

```
640000 FEFEFE 010101 AD9C83 CBB5AB 646464 FFDD46 A50003 7D6E6E
```

For the selected row, `k.b(Graphics)` uses `b[6]` as the fill and `b[7]` as the
selected text color.  Therefore the played reference is:

- selection band: `#FFDD46`
- selected glyphs: `#A50003`

The alternative `#90C0D6`/white branch is gated by the device-mode path and does
not match the supplied reference capture.

## Menu sky

The capture's dominant sky colors are `#9AC8EA` with a top `#80BBE7` cap and
the Java renderer's averaged transition color between them.  These are adjacent
entries 1 and 2 of `House.<clinit>`'s recovered sky array.

Using the recovered `House.a(Graphics,int,boolean)` horizon formula, an 11-pixel
cap corresponds to `camera_y = 3264` at the GBA 240x160 viewport.  The GBA menu
background is therefore generated by the same clean-room sky routine used for
gameplay rather than by copying a screenshot.

During this audit several earlier transcription errors in the later `House`
sky entries were also corrected directly against bytecode.  The exact array is:

```
B2D6F2 9AC8EA 80BBE7 66AFE4 518EE4 407ABE 1C5B96 0C3F7C 13306A
34204C 372C51 2D4B4B 4A6742 674723 532733 802A2B 511A2F
```

## Source bitmap resources

The menu capture is composed from normal JAR resources rather than a single
menu texture:

| Resource | Recovered use |
| --- | --- |
| 2 | Continue/play icon |
| 3 | Build City icon |
| 4 | Quick Game icon |
| 5 | Settings icon |
| 6 | Exit icon |
| 7 | Tower Bloxx logo (109x26) |
| 11 | Blue worker/umbrella animation, 10 frames of 19x23 |
| 36 + 44 | bitmap font atlas + metrics |

The GBA exporter now slices all five menu icons and all ten worker frames into
Butano OBJ assets.  The worker animation is advanced independently of menu
selection changes.

## Scope boundary

This pass fixes the **composition layer**: sky, logo, selection colors, menu
source sprites and worker animation.  The native GBA controller still uses its
existing simplified `New game -> Quick Game / Build City` hierarchy.  The
played JAR capture also proves a richer visible root menu (`Continue game`,
`Build City`, `Quick Game`, `High Scores`, `Settings`, `Instructions`, `Exit`).
Its exact conditional descriptor/state behavior in `l`/resource `m` should be
recovered before replacing the controller, rather than guessing how Continue
and Exit should map to GBA state.

Likewise, Quick Game and Build City use separate scene compositors and HUD
resources.  Their screenshot parity is intentionally handled in following
passes so visual work does not alter the already-tested gameplay cores.
